# NxtWave Growth Intern Challenge – Round 1

## AI Workshop Growth Engine

A functional web prototype created for the NxtWave Growth Intern Challenge.

### Challenge

NxtWave plans to launch a free online workshop:

**“Build Your First AI Project in 60 Minutes”**

The objective is to design a growth strategy to get **500 final-year engineering students** to register within:

- **Budget:** ₹2,000
- **Campaign Duration:** 7 Days
- **Target:** 500 Registrations

## Target Students

The primary audience is final-year engineering students, especially students who:

- Are preparing for placements
- Want practical AI skills
- Want to build stronger projects for their resumes
- Are interested in learning AI through hands-on experience

## Growth Approach

Instead of relying only on a traditional landing page, this project uses a product-led referral approach.

The core growth loop is:

**Student discovers workshop → Registers → Receives referral code → Shares with friends → Friend registers → Referral is tracked → Student's progress updates → More sharing**

This approach aims to turn registered students into potential acquisition channels.

## Working Asset

The web application includes:

- Workshop registration
- Student information collection
- Referral code generation
- Referral sharing
- WhatsApp sharing
- Referral tracking
- Leaderboard
- Interactive workshop-related experience
- Growth/evaluator view

## Growth Channels

The proposed campaign prioritizes:

1. Student ambassadors and class representatives
2. College student communities
3. WhatsApp and other peer-to-peer communities
4. Student referral sharing

## Budget Strategy

The ₹2,000 budget is primarily intended for referral and student-community activation rather than large-scale paid advertising.

| Activity | Budget |
|---|---:|
| Referral / leaderboard incentives | ₹1,200 |
| Student / CR activation | ₹800 |
| **Total** | **₹2,000** |

## Registration Target

The campaign uses the following target model:

| Source | Target |
|---|---:|
| Student ambassadors / CRs | 250 |
| College communities | 150 |
| Referral loop | 100 |
| **Total** | **500** |

These are campaign targets for the simulation and are not actual campaign results.

## Growth Funnel

**Discovery → Registration → Referral → Sharing → New Registration → Referral Attribution**

The key metrics that can be monitored include:

- Registrations
- Referral registrations
- Referral participation
- Registrations by source
- Top referrers
- Student engagement

## AI-Assisted Development

AI was used throughout the development process to:

- Explore growth strategies
- Structure the product idea
- Design the user experience
- Generate and improve code
- Debug implementation issues
- Review the growth mechanism
- Iterate on the prototype

AI suggestions were evaluated against the challenge constraints, and the final decisions were made based on practicality, time, budget, and expected growth impact.
